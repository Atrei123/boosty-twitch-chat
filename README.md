# Boosty Chat - Twitch-style

Делает чат Boosty похожим на чат Twitch и выводит его в OBS как обычный оверлей.

Состоит из двух частей:

| Часть | Что делает |
|---|---|
| `extension/` — расширение для Chrome / Яндекс Браузера / Edge (или userscript для Tampermonkey) | На странице чата Boosty показывает сообщения в стиле Twitch: компактные строки, цветные ники, значки стримера и модераторов, смайлы, ответы, «<сообщение удалено>», автопрокрутка с паузой. Каждое сообщение отправляет в relay. |
| `relay/` — маленький локальный сервер (Node.js, без зависимостей) | Принимает сообщения от расширения и отдаёт оверлей для OBS: `http://127.0.0.1:8787/overlay`. Есть страница настройки с превью. |

```
boosty.to/…/only-chat  ──(расширение читает чат)──►  relay 127.0.0.1:8787  ──►  OBS Browser Source /overlay
```

Расширение не подключается к Boosty само и не требует логина или токенов: оно читает сообщения, которые Boosty уже показывает на странице.

## Безопасность: что программа делает и чего не делает

Весь код открыт и небольшой, около 1300 строк обычного JavaScript и HTML без сборки и сторонних библиотек. Его можно прочитать целиком, и то, что вы читаете, и запускается.

**Не делает:**
- не просит логин, пароль или токены Boosty, не читает cookies;
- не пишет в чат, не нажимает кнопки, не модерирует от вашего имени;
- не отправляет данные в интернет: ни на наши серверы, ни на чужие (их просто нет);
- не ставит ничего в систему, не требует прав администратора, не запускается сам.

**Делает:**
- на странице `boosty.to` читает сообщения чата, которые Boosty уже показывает на экране, и рисует их в другом виде;
- отправляет эти сообщения только на ваш же компьютер, на адрес `127.0.0.1` (relay). Другой адрес код не примет: проверки есть в [`extension/boosty-twitch-chat.user.js`](extension/boosty-twitch-chat.user.js) (функция `post`) и [`extension/background.js`](extension/background.js);
- relay ([`relay/server.js`](relay/server.js)) слушает только `127.0.0.1`, поэтому из интернета и даже из локальной сети он недоступен;
- оверлей в OBS загружает картинки смайлов и аватарок с серверов Boosty, как и сам чат Boosty.

**Права расширения** ([`extension/manifest.json`](extension/manifest.json)): работает только на `https://boosty.to/*` и может обращаться только к `http://127.0.0.1` и `http://localhost`. Никаких прав на «все сайты», историю, вкладки или cookies.

Проверить самостоятельно:
- поищите в коде `fetch`, `XMLHttpRequest`, `WebSocket`: все обращения идут только к relay на `127.0.0.1`;
- откройте F12 → Network на странице Boosty: запросы расширения идут только на `127.0.0.1:8787`.

## Установка

### 0. Скачать

1. Вверху [страницы проекта](https://github.com/Atrei123/boosty-twitch-chat) нажмите зелёную кнопку **Code → Download ZIP**.
2. Нажмите на скачанный архив правой кнопкой → **«Извлечь все…»**. Запускать файлы прямо из zip нельзя.

### 1. Relay

1. Установите [Node.js](https://nodejs.org/ru/download): скачайте **установщик Windows (.msi)**, запустите его и после установки перезагрузите компьютер.
2. Запустите `relay/start.bat` на Windows или `relay/start.sh` на macOS / Linux.
3. Откроется страница `http://127.0.0.1:8787/`. Окно relay не закрывайте, пока идёт стрим.

### 2. Расширение (выберите один вариант)

**Вариант A: расширение Chrome / Яндекс / Edge**
1. Откройте `chrome://extensions` (в Яндексе `browser://extensions`).
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное» и выберите папку `extension`.

**Вариант B: Tampermonkey / Violentmonkey**
1. Откройте панель Tampermonkey → «+» (новый скрипт).
2. Вставьте всё содержимое `extension/boosty-twitch-chat.user.js` и сохраните.

### 3. OBS

1. На странице `http://127.0.0.1:8787/` выберите размер шрифта, фон, автоскрытие и т. д.
2. Скопируйте ссылку на оверлей.
3. В OBS: «Источники» → «+» → «Браузер», вставьте ссылку и задайте размер, например 400 × 600.
4. В браузере откройте чат: `https://boosty.to/hellyeahplay/streams/only-chat`. Вкладку можно свернуть, но не закрывать.

Индикатор на странице настройки и точка «OBS» в чате станут зелёными, когда всё связано. Кнопка «Отправить тестовое сообщение» проверяет OBS даже без запущенного стрима.

## Twitch-вид в браузере

Панель появляется при наведении на чат (справа сверху):

- **OBS**: включить или выключить отправку в relay. Зелёная точка — relay на связи, красная — relay не запущен.
- **A− / A+**: размер шрифта.
- **🕑 / 👤**: время сообщений и аватарки.
- **Boosty** или **Alt+B**: вернуть обычный чат Boosty, например чтобы открыть меню модерации по клику на ник.

Поле ввода Boosty остаётся на месте, писать в чат можно как обычно. Настройки запоминаются.

## Параметры оверлея

Все параметры добавляются к ссылке, например `/overlay?font=22&fade=30&hide=nightbot`. Удобнее всего собрать ссылку на странице настройки.

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `font` | `18` | размер шрифта, px |
| `bg` | `transparent` | `transparent`, `dark` или цвет без `#` (`00ff00` для хромакея) |
| `bgalpha` | `100` | непрозрачность фона, 0–100 (для `bg=dark` или цвета) |
| `plate` | `0` | тёмная подложка под каждым сообщением, 0–100 (`0` — без подложки) |
| `alpha` | `100` | непрозрачность самих сообщений, 5–100 |
| `fade` | `0` | скрывать сообщение через N секунд (`0` — не скрывать) |
| `max` | `40` | сколько строк держать на экране |
| `time` | `0` | показывать время |
| `avatars` | `0` | показывать аватарки |
| `badges` | `1` | значки стримера / модератора |
| `shadow` | `1` | обводка текста, чтобы читалось поверх игры |
| `history` | `1` | показывать сообщения, которые были до открытия оверлея |
| `commands` | `1` | `0` — скрывать сообщения, начинающиеся с `!` |
| `hide` | — | ники через запятую, чьи сообщения скрывать (боты) |
| `deleted` | `0` | `1` — показывать «<сообщение удалено>» вместо того, чтобы убирать строку |
| `system` | `0` | `1` — показывать системные сообщения Boosty |
| `status` | `0` | `1` — подсказка о соединении (для настройки, не для эфира) |

Порт relay меняется так: `PORT=9000 node relay/server.js`. Если вы его поменяли, укажите тот же адрес в расширении: в консоли страницы Boosty выполните `localStorage.setItem('boosty-twitch-chat:v1', JSON.stringify({relayUrl:'http://127.0.0.1:9000'}))` и обновите страницу.

## Как это устроено и что может сломаться

- Сообщения читаются по атрибутам `data-test-id="CHATMESSAGE:root|author|message"`. Boosty меняет имена CSS-классов при каждом релизе, а эти атрибуты стабильны. Значки стримера и модератора определяются по иконкам `icon-star` / `icon-sword`, удаление — по классу `msgBanned` / `userBanned`.
- Если Boosty переделает вёрстку чата, расширение перестанет видеть сообщения. Тогда нужно поправить селекторы в блоке `SEL` в начале `boosty-twitch-chat.user.js`.
- Уровни подписки в строке сообщения Boosty не показывает, поэтому их нет и здесь.
- Relay слушает только `127.0.0.1`: из сети он недоступен.

## Проверка

`test/e2e.js` запускает настоящее расширение в Chromium на копии страницы чата Boosty (по реальной разметке), поднимает relay, открывает оверлей и проверяет сообщения, значки, смайлы, ответы, удаление и перезапуск оверлея:

```bash
npm i -D playwright && npx playwright install chromium
node test/e2e.js
```
